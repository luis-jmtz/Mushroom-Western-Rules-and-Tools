**Project Status: Archived/No Longer Maintained**

This repository contains an incomplete prototype of a homebrew TTRPG (Tabletop Role-Playing Game) system built with Python. The project is no longer under active development and is preserved here for reference purposes only.

## Overview

This was an experimental prototype exploring the creation of digital tools and rule systems for a custom TTRPG. The implementation focuses on data management and web-based interfaces using popular Python libraries.

## Tech Stack

-   **Python** - Primary programming language
    
-   **Pandas** - Data manipulation and analysis
    
-   **Streamlit** - Web application framework for creating interactive tools
